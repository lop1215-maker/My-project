## 1. Задание

Реверсивное отображение данных: разработать программу, которая считывает список данных  
(например, имён или дат) и выводит их в обратном порядке с помощью обратных итераторов.

## 2. Описание алгоритма

Программа запрашивает количество элементов списка.

Создаётся контейнер `vector<string>` для хранения введённых данных.

С помощью цикла пользователь вводит элементы, которые добавляются в конец вектора через `push_back()`.

Для вывода элементов в обратном порядке используются обратные итераторы:
- `rbegin()` — указывает на последний элемент контейнера;
- `rend()` — указывает на позицию перед первым элементом контейнера.

С помощью цикла программа проходит по контейнеру от конца к началу и выводит все элементы в обратном порядке.

## 3. Код

```cpp
#include <iostream>
#include <vector>
#include <string>

using namespace std;

int main() {
    int n;
    cout << "Сколько элементов вы хотите ввести? ";
    cin >> n;

    vector<string> data;

    cout << "Введите элементы списка:\n";
    for (int i = 0; i < n; i++) {
        string item;
        cin >> item;
        data.push_back(item);
    }

    cout << "\nЭлементы в обратном порядке:\n";

    for (vector<string>::reverse_iterator it = data.rbegin(); it != data.rend(); it++) {
        cout << *it << " ";
    }

    cout << endl;

    return 0;
}
```
