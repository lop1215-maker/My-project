## 1. Задание

Мульти-итератор для объединения данных из различных источников: создать итератор,  
который позволяет последовательно перебирать элементы из различных контейнеров,  
например, из списка email-адресов и списка телефонных номеров, обеспечивая  
унифицированный доступ к этим разнородным данным.

## 2. Описание алгоритма

Программа создаёт два контейнера:
- `emails` — для хранения email-адресов;
- `phones` — для хранения телефонных номеров.

Пользователь вводит количество элементов для каждого контейнера, после чего данные заносятся в векторы.

Далее создаётся пользовательский класс `MultiIterator`, который:
- хранит ссылки на два контейнера;
- хранит текущую позицию;
- умеет проверять наличие следующего элемента;
- умеет возвращать следующий элемент.

Если текущий индекс меньше размера первого контейнера, возвращается элемент из первого контейнера.

Если индекс выходит за границы первого контейнера, итератор начинает возвращать элементы второго контейнера.

Таким образом, пользовательский мульти-итератор позволяет обойти два разных контейнера как одну общую последовательность.

## 3. Код

```cpp
#include <iostream>
#include <vector>
#include <string>

using namespace std;

class MultiIterator {
private:
    vector<string>& first;
    vector<string>& second;
    int index;

public:
    MultiIterator(vector<string>& a, vector<string>& b) : first(a), second(b) {
        index = 0;
    }

    bool hasNext() {
        return index < first.size() + second.size();
    }

    string next() {
        string result;

        if (index < first.size()) {
            result = first[index];
        } else {
            result = second[index - first.size()];
        }

        index++;
        return result;
    }
};

int main() {
    vector<string> emails;
    vector<string> phones;

    int n, m;

    cout << "Сколько email-адресов? ";
    cin >> n;

    cout << "Введите email-адреса:\n";
    for (int i = 0; i < n; i++) {
        string email;
        cin >> email;
        emails.push_back(email);
    }

    cout << "Сколько телефонных номеров? ";
    cin >> m;

    cout << "Введите номера телефонов:\n";
    for (int i = 0; i < m; i++) {
        string phone;
        cin >> phone;
        phones.push_back(phone);
    }

    MultiIterator it(emails, phones);

    cout << "\nВсе элементы по очереди:\n";
    while (it.hasNext()) {
        cout << it.next() << endl;
    }

    return 0;
}
```
