1. Задание:

Реализовать шаблонный класс MyPipeline<T>, представляющий собой конвейер обработки данных.

Класс должен:

хранить последовательность шагов обработки;

позволять добавлять и удалять шаги;

выполнять последовательное применение шагов к значению;

возвращать промежуточные результаты;

поддерживать вывод в поток std::ostream;

демонстрировать работу с типами int и std::string;

продемонстрировать обработку исключений.

2. Описание алгоритма:

Класс MyPipeline<T> является шаблонным и может работать с любым типом данных T.

Внутри класса хранятся:

вектор stepNames — имена шагов;

вектор stepFunctions — функции обработки.

Каждый шаг представляет собой функцию вида T(T).

Метод addStep

Принимает имя шага и функцию.
Если имя пустое — выбрасывается исключение invalid_argument.
Функция и имя добавляются в соответствующие векторы.

Метод removeStep

Удаляет шаг по индексу.
Если индекс выходит за границы — выбрасывается исключение out_of_range.

Метод run

Последовательно применяет все функции к переданному значению и возвращает итоговый результат.

Метод trace

Последовательно применяет шаги и сохраняет каждый промежуточный результат в вектор, который затем возвращается.

Перегруженный оператор <<

Позволяет вывести список шагов и их количество.

В функции main

Создаются два конвейера:

Для типа int

выполняются арифметические операции;

демонстрируется работа run и trace.

Для типа std::string

выполняются операции над строкой.

Также демонстрируется обработка исключения при удалении шага с неправильным индексом.
